Phase 5 local teaching engine

Local ingestion, anomaly detection, and operator teaching are available in the Python library. Sensor replay and voice capture remain unavailable. Live APIs are planned for Phase 7.

Exercise the local teaching engine with tests/test_policy.py and read the results in docs/PHASE_5_REPORT.md. Backend health reports library capabilities; it does not indicate that the live APIs are ready.

Inspect the dataset with scripts/explore_schema.py and scripts/build_dataset.py. The resulting local Parquet files and data/processed/schema_report.md contain the processed data and discovery findings.

Generate baseline metrics with scripts/compute_baseline.py. Read the local report at data/processed/baseline_report.md and its machine-readable results at demo/baseline_stats.json. This page does not display computed results or live monitoring.
