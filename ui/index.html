Phase 7 live replay API

Real alarm events and sensor snapshots now replay through the local API. Text teaching, undo, saved rules, statistics, and the offline switch are live. The operator console and voice capture are later phases.

Send an operator instruction to POST /teach to parse and apply a local correction. Connect to WS /stream for events and updates, or use POST /undo/{rule_id} to revoke a correction. Read docs/PHASE_7_REPORT.md for verification and examples.

Exercise the local teaching engine with tests/test_policy.py and read the results in docs/PHASE_5_REPORT.md. Health reports the replay position and model version. If local inputs cannot be loaded, it explains why the runtime is unavailable.

Inspect the dataset with scripts/explore_schema.py and scripts/build_dataset.py. The resulting local Parquet files and data/processed/schema_report.md contain the processed data and discovery findings.

Generate baseline metrics with scripts/compute_baseline.py. Read the local report at data/processed/baseline_report.md and its machine-readable results at demo/baseline_stats.json.
