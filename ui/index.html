Phase 3 dataset ingestion

Local schema discovery and dataset ingestion are implemented through the command-line scripts. Sensor replay, anomaly detection, voice corrections, and local learning are not implemented.

Inspect the dataset with scripts/explore_schema.py and scripts/build_dataset.py. The resulting local Parquet files and data/processed/schema_report.md contain the processed data and discovery findings. This page does not display dataset results or live monitoring.
